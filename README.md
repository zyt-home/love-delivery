# 心动投递局 · The Love Post

一个奶油纸张与樱桃红风格的表白小游戏。五站约 5 分钟的旅程：接住心动、翻牌配对、记忆暗号、礼物分拣和六题约会问答，最后拆开告白信。

## 使用

直接打开 `index.html`，或使用任意静态 HTTP 服务预览。所有资源均在仓库内，不需要安装依赖或构建。

点击“定制这封信”可以填写收件人、署名与告白内容，生成分享链接。文字保存在 URL 参数中，拿到链接的人可以看到。页面不保存或上传游戏回应。

## 发布

GitHub Pages 使用 `main` 分支根目录。`.nojekyll` 让 GitHub 按原样发布静态文件。

## 操作

- 前四关各 60 秒，问答与读信按自己的速度完成；完整路线约 5 分钟。
- 支持手机触摸与键盘 Tab / Enter；可手动暂停，切到后台或定制窗口时自动暂停。
- 拒绝趣味按钮在窗口内躲开鼠标和触摸，点击不会提交回应；另有固定的认真退出入口。
- 可直接拆信、重新游玩，也可以接受或婉拒。
- 尊重系统的减少动态效果设置。
- 复制不可用时显示可手动复制的链接。
